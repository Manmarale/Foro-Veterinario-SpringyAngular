# 🐾 Foro Veterinario - Frontend (Angular)

Frontend del Foro Veterinario desarrollado con Angular 15 y Angular Material.

## Tecnologías

- **Angular 15** + **TypeScript**
- **Angular Material 15**
- **Bootstrap 5**
- **SweetAlert2**
- **JWT** para autenticación

## Funcionalidades

- Foro de discusión con categorías veterinarias
- Registro con roles (Veterinario, Estudiante, Propietario)
- Gestión de mascotas con fotos
- Calendario de vacunas interactivo
- Diseño responsive con tema veterinario (verde)
- Panel de administración

## Estructura

```
src/app/
├── admin/       # Módulo de administración
├── auth/        # Login, registro, guards, interceptor JWT
├── home/        # Módulo público (temas, foro)
├── mascotas/    # Módulo de gestión de mascotas y vacunas
├── interfaces/  # Interfaces TypeScript compartidas
├── material/    # Módulo Angular Material
└── shared/      # Pipes y componentes compartidos
```
